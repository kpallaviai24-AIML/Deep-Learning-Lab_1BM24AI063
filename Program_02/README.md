# PROGRAM 02 – Data Analysis and Visualization

## Objective
To perform basic data analysis using Python and visualize the results using Matplotlib.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib

## Implementation
1. Create a sample dataset.
2. Load the dataset using Pandas.
3. Display the first five records.
4. Calculate basic statistical information.
5. Visualize the data using bar and line charts.
6. Save the generated charts in the outputs folder.

## How to Run

Open the terminal inside the Program_02 folder.

```bash
pip install -r code/requirements.txt
python code/main.py
```

## Output
The program generates:
- `bar_chart.png`
- `line_chart.png`
- `analysis_results.csv`

All generated files are stored in the `outputs` folder.
