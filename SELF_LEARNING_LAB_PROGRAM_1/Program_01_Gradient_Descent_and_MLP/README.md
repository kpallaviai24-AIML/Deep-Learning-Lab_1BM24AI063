
# Program 01: Gradient Descent and MLP

## Objective
To demonstrate different gradient descent algorithms and study optimization techniques, overfitting, regularization, early stopping, and neural network architectures using an MLP on a subset of Fashion-MNIST.

## Experiments

1. Batch Gradient Descent
2. Stochastic Gradient Descent
3. Mini-Batch Gradient Descent
4. Comparison of Optimizers
5. Constant and Scheduled Learning Rates
6. Overfitting Analysis
7. Regularization Techniques
8. Early Stopping
9. Plain MLP vs Residual MLP

## Dataset
Fashion-MNIST dataset.

The dataset contains grayscale images of clothing items belonging to 10 classes.

## Libraries
- PyTorch
- NumPy
- Pandas
- Matplotlib
- Torchvision
- Scikit-learn

## Installation

```bash
pip install -r requirements.txt
```

## Execution
Run the Python files inside their respective experiment folders.

## Results
Graphs and CSV files are automatically saved inside the corresponding outputs folders.
