# PROGRAM 03 – Machine Learning Classification

## Objective
To implement a machine learning classification model using the Iris dataset.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Implementation
1. Load the Iris dataset.
2. Separate input features and target labels.
3. Split the dataset into training and testing sets.
4. Train a Logistic Regression classifier.
5. Predict the output for test data.
6. Calculate model accuracy.
7. Display the confusion matrix.
8. Save the results and visualization.

## How to Run

Open the terminal inside the Program_03 folder.

```bash
pip install -r code/requirements.txt
python code/main.py
```

## Output
The program generates:
- `confusion_matrix.png`
- `classification_results.csv`

All generated files are stored in the outputs folder.
